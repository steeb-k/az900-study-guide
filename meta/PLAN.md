# AZ-900 study kit: content plan

This repo holds the content only: the markdown study guide, the question bank, and the exam settings. The practice site and
the HTML guide are generated from it by the engine repo, [steeb-k/study](https://github.com/steeb-k/study) (local clone
`~/study`). The engine specs (design, guide site, question schema, adding an exam) are in that repo's `docs/`.

## What is here
```

00-exam-overview.md                 format, domains & weights, question types, scoring, test-day tactics, schedules
```

## Content style
Compact, for a reader who already works in IT. Microsoft does not number its skill groups; this kit numbers them d.n
(`## 2.3 Describe Azure storage services`) so the quiz can deep-link. Every outline bullet gets a definition framed the way
the exam tests it; tables for compare/contrast sets; `> **Exam tip:**` callouts for commonly confused pairs; each domain ends
with "Most-tested distinctions". Each file carries a one-line AI-generated disclaimer that the build strips from the site.
Source outline: Microsoft's AZ-900 study guide, skills measured as of July 20, 2026.

The acronym table (`91-acronyms.md`) feeds the quiz feedback panel and the guide tooltips. Lookup is case-sensitive on the
key, so when the bank or chapters spell an acronym two ways, list both in one row with the alias form (`IMAP (IMAP4)`).

## Exam model
Microsoft AZ-900: 45 minutes, scored 1-1000, pass 700; Microsoft does not publish the question count (commonly about 35-45).
No labs. The site's final exam is 40 items: 4 interactive items first (spread across domains), then 36 MCQs by weight: D1 10,
D2 14, D3 12. The scaled score is a straight percentage estimate, not Microsoft's scaling. Readiness is green when the last 3
module attempts in a domain are at or above 80%. These numbers live in `exam.json`.

The real AZ-900 has no labs, but it has yes/no statement grids, drag-and-drop matching, and dropdown completion. The site
serves those with its performance-based-item engine (named `PBQ` in code); the reader sees "interactive items".

## Question bank style
A short scenario and then "What should you use?", "Which Azure service should you recommend?", "Which cloud model ...?",
"Which benefit of cloud computing does this describe?", plus direct recall and sentence completion. Microsoft does not
capitalize BEST/MOST; neither does the bank. Target mix per domain: about 35% difficulty 1, 50% difficulty 2, 15% difficulty 3;
about 12-15% `multi`. Use current product names (Microsoft Entra ID, Microsoft Defender for Cloud, Microsoft Purview). Do not
test retired items (TCO calculator, Azure Blueprints), prices in currency, or preview features. Vary the scenario organization
(retailer, hospital, startup, school, bank). At least 18 interactive items, at least 3 per domain, a mix of match, order, and
config. Questions are original: none copied from Microsoft's practice assessment or from any exam. Format and mechanical rules:
`~/study/docs/QUESTION-SCHEMA.md`.

## Rebuild after any change
From `~/study`:
```
python3 tools/build.py az-900        # site data, shells, STUDY-GUIDE-FULL.md in this repo, hub
bash tests/run.sh az-900
```
Run this after editing a chapter, `exam.json`, `bank/`, or `icons/`, then commit this repo and the engine repo. Live at
https://steeb-k.github.io/study/az-900/ and https://steeb-k.github.io/study/az-900/guide/.
